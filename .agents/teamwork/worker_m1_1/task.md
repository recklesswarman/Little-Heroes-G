Scope:
- Build `src/services/avatarSkeletalRig.js`: Procedural 3D character avatar with articulated skeletal bone hierarchy using Three.js (pelvis, spine, chest, neck, head, shoulders, arms, hands, hips, knees, feet, cape).
- Build `src/services/workoutKinematicsEngine.js`: Pure mathematical forward-kinematic engine driving bone rotations and translations for all 8 prehistoric gross-motor routines (Velociraptor, Stegosaurus, Pterodactyl, T-Rex, Compsognathus, Brachiosaurus, Diplodocus, Spinosaurus).
- Build `src/components/WorkoutHero3DStage.js`: 3D WebGL stage mounting Three.js scene side-by-side, lifecycle management, and graceful runtime fallback to WorkoutHeroDuoCanvas on WebGL failure or context loss.
- Verify npm run build passes with exit code 0.
