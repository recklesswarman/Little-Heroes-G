# Kenney sound effects

These short clips come from Kenney's official open-source Starter Kits
(https://kenney.nl, https://github.com/KenneyNL). They were converted from Ogg
to MP3 (mono, 64 kbps) so Safari and iPad play them too.

| File | Source |
| --- | --- |
| coin.mp3, jump.mp3, fall.mp3 | KenneyNL/Starter-Kit-3D-Platformer `sounds/` |
| match.mp3, swap.mp3 | KenneyNL/Starter-Kit-Match-3 `sounds/tile-match.ogg`, `tile-swap.ogg` |
| place.mp3 | KenneyNL/Starter-Kit-City-Builder `sounds/placement-a.ogg` |
